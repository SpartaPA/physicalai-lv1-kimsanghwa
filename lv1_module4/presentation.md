## 1. 파이프라인 전체 구조

- 좌표계 체인 (base -> link -> camera -> object): `base --T_base_link--> link --T_link_camera--> camera --(관측)--> 물체 점군`. `01_pipeline.ipynb` 의 4-프레임 3D 시각화에서 각 좌표계의 x(빨강)·y(초록)·z(파랑) 축을 확인할 수 있다.
- 각 노트북·모듈이 맡는 역할:
  - `01_pipeline.ipynb` — venv/커널 확인, 4개 좌표계 정의, `PosePipeline` 으로 camera→base 점군 변환과 관절 각도 변화 실험
  - `02_interpolation.ipynb` — 쿼터니언 변환·SLERP 구현/검증, 선형·큐빅 스플라인·5차 다항식 궤적 보간과 연속성 비교
  - `03_pose_estimation.ipynb` — PCA·Kabsch·최소제곱으로 점군에서 물체 자세 추정, SLERP+스플라인 궤적으로 시연 애니메이션 생성
- 데이터 흐름: 카메라 점군 -> `PosePipeline.camera_to_base` -> base 점군 -> PCA/Kabsch 로 자세 추정 -> 목표 자세 `T_goal` -> SLERP(자세) + 큐빅 스플라인(위치) 동시 보간 -> `demo.gif` 애니메이션
- 모듈 ③ 에서 가져온 함수: `rotation.py` (`rot_x/y/z`, `rodrigues`, `axis_angle_from_matrix` 등), `transform.py` (`make_T`, `inv_T`, `transform_points`), `coordinate_chain.py` (`default_chain`). 이번에 새로 만든 함수: `pose_pipeline.PosePipeline`, `quaternion.py` (`matrix_to_quaternion`, `quaternion_to_matrix`, `slerp`, `lerp_quat`), `trajectory.py` (선형·큐빅 스플라인·5차 다항식 보간), `pose_estimation.py` (`pca_axes`, `kabsch`, `fit_plane_lstsq`, `remove_outliers`).

## 3. 노이즈·점 개수가 정확도에 미친 영향

- 노이즈 0 ~ 0.25 스윕에서 오차가 어떻게 커졌는가: 세 점 개수(30/90/270) 계열 모두 노이즈 표준편차가 커질수록 각도 오차가 대체로 증가한다 (노이즈 0에서 오차 ~0도, 노이즈 0.25 근처에서 30개는 약 20도, 270개는 약 9도까지 상승).
- 점 개수 30 / 90 / 270 계열 비교: 같은 노이즈 수준에서 점이 많을수록 오차가 작다. 고노이즈 구간 평균 기준 270개가 30개보다 약 **3배 이상** 정확하며, 이는 Kabsch 정합이 여러 점의 평균적 통계에 의존해 노이즈가 `1/sqrt(N)` 로 상쇄되는 것과 대략 일치한다(점 개수를 9배 늘리면 이론상 오차가 3배 줄어든다).
- 구형 점군에서 PCA 주축이 불안정해진 이유: 표준편차가 (0.20, 0.19, 0.18) 로 비슷해 세 고유값이 거의 같아지고(λ1/λ2 ≈ 1.19, 길쭉한 경우 12.37과 대비), 고유공간이 사실상 축퇴돼 "분산이 가장 큰 방향"이 샘플마다 임의로 흔들린다 (흔들림 72.7도 vs 길쭉한 경우 2.5도).
- 오차 그래프: `03_pose_estimation.ipynb` 5-4 절 그래프 (노이즈 x 점 개수 3계열) 참조.

## 4. 현재 구현의 한계

- 자세 추정: Kabsch 는 두 점군의 대응(순서)이 알려져 있어야만 동작하며, 실제 센서에서는 대응을 별도로 찾아야 한다(ICP 등). 또한 물체가 좌우 대칭이면 PCA 주축의 부호/축 선택이 모호해질 수 있다.
- 궤적 생성: 위치·자세 보간에서 충돌 회피나 로봇 관절 각도·속도·토크 한계를 전혀 고려하지 않았다. 순수 작업 공간(task-space) 궤적이라 역기구학이 항상 풀린다는 보장이 없다.
- 파이프라인: 관절을 1개(z축 회전)로 단순화했고, 카메라-링크 캘리브레이션 오차나 센서 지연은 반영하지 않았다.
- 시연: 애니메이션은 이상적인 값만 보여주며 실제 그리퍼의 물리적 충돌·파지 성공 여부는 검증하지 않는다.

## 5. 개선한다면 무엇을 어떻게

- 대응 없는 점군 정합 -> ICP(Iterative Closest Point)로 Kabsch 앞단에 대응점 탐색을 추가한다.
- 이상치에 더 강건한 정합 -> RANSAC 기반 평면/자세 피팅으로 반복적으로 인라이어를 선택한다.
- 궤적 품질 개선 -> 최소 저크(jerk) 궤적이나 관절 한계를 제약 조건으로 넣는 최적화 기반 궤적 생성으로 교체한다.
- 개선 효과를 어떻게 측정할 것인지: 동일한 노이즈·점 개수 스윕(5-4 절과 같은 실험)을 다시 돌려 각도 오차 곡선이 얼마나 아래로 내려가는지, 그리고 궤적의 가속도 점프(6-2 절 지표)가 얼마나 줄어드는지를 정량 비교한다.
